01 / Overview

Long-horizon manipulation hinges on memory.

A block's color seen early in a task may be hidden by the time the robot needs it, yet most vision-language-action (VLA) models act from the current observation alone.

Existing memory methods store raw history, compressed visual tokens, or language summaries, but they either burden the policy with an ever-growing context or discard the temporal, semantic, and perceptual details that matter later.

We introduce Mem4Act, which continuously distills past observations into a compact, fixed-size latent memory trained explicitly for control. Multi-granularity temporal attention structures this memory across time scales; semantic question answering and key-frame DINO feature reconstruction teach it to retain both task facts and fine visual detail; and memory-first two-stage training ensures the policy actually draws on memory instead of reacting only to what it currently sees.

02 / Method

Three questions for effective latent memory.

Effective latent memory must answer where to attend, what to retain, and how to make the policy use it. Mem4Act tackles each one directly.

How do memory capacity and temporal structure affect performance?

Finding

Structure matters more than size. Growing memory from 128 to 512 tokens lifts success from 40.13% to 49.88%, but 1024 tokens drops it to 42.75%. A structured 128-token memory already beats unmasked full-history attention with 512 tokens (33.25%), and the default 32→16→8 hierarchy beats both coarser and finer scales.

Q2
Content

Do semantic and perceptual objectives complement each other?

Finding

QA and DINO are complementary. QA supervision helps most on semantic tasks (58.80% vs. 55.60% for DINO), while key-frame DINO reconstruction helps most on perceptual tasks (50.67% vs. 45.33% for QA). Using both gives the best joint-task (37.60%) and overall (49.88%) success.

Q3
Utilization

Does pretrained memory need to adapt for control?

Finding

Adapt memory, but gently. Freezing the pretrained memory collapses success to 18.38%. Updating it at 0.1× the action learning rate works best (49.88%), ahead of full-rate adaptation (43.25%) and one-stage joint training (33.38%).

Q4
Utilization

Does two-stage training make the policy rely on memory?

Finding

Memory-first training makes the policy actually use history. Swapping in another rollout's past costs the 0.1× LR two-stage model 33.75 points, twice the drop of one-stage training (16.75). It is also the best model with the correct history, so it relies on rollout-specific memory rather than the current frame alone.
